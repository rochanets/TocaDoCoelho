### 📥 Download & Instalação

#### Linux / WSL2
```bash
# Fazer download do arquivo
wget https://github.com/rochanets/TocaDoCoelho/releases/download/v5.3.0.3/TocaDoCoelho

# Dar permissão de execução
chmod +x TocaDoCoelho

# Executar
./TocaDoCoelho
```

#### Windows (via WSL2)
```cmd
# Abrir WSL2 terminal
wsl

# Navegar até o arquivo
cd /mnt/c/Downloads

# Executar
./TocaDoCoelho
```
